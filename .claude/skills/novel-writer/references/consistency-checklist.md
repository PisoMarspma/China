## 角色一致性

### 基本信息

**检查项目**：
- [ ] 角色姓名是否前后一致
- [ ] 角色年龄是否随时间正确增长
- [ ] 角色外貌描述是否前后一致
- [ ] 角色身份/职业是否前后一致

**常见错误**：
- 名字写错字或前后不一致
- 年龄没有随时间变化
- 外貌描述前后矛盾（如前面说黑色头发，后面说棕色）

### 性格特点

**检查项目**：
- [ ] 角色性格是否前后一致
- [ ] 角色说话风格是否一致
- [ ] 角色行为是否符合其性格设定
- [ ] 角色性格变化是否有合理铺垫

**常见错误**：
- 性格突然改变没有原因
- 说话风格不一致（如前面沉默寡言，后面突然话多）
- 行为与性格设定不符

### 能力设定

**检查项目**：
- [ ] 角色能力是否符合设定
- [ ] 能力提升是否有合理过程
- [ ] 是否出现超出能力范围的表现
- [ ] 金手指使用是否符合规则

**常见错误**：
- 主角突然会了没学过的技能
- 能力提升太突兀
- 金手指规则前后矛盾

## 时间线一致性

### 时间顺序

**检查项目**：
- [ ] 事件发生顺序是否合理
- [ ] 是否有时间跳跃，跳跃是否合理
- [ ] 季节/天气描写是否与时间匹配
- [ ] 节日/纪念日是否与时间线吻合

**常见错误**：
- 前面说春天，后面描写却像夏天
- 事件顺序混乱
- 时间跨度计算错误

### 时间跨度

**检查项目**：
- [ ] 每个阶段的时间跨度是否明确
- [ ] 角色成长速度是否合理
- [ ] 公司发展速度是否合理
- [ ] 感情发展速度是否合理

**常见错误**：
- 公司从成立到上市只用了几个月
- 感情发展太快，不自然
- 时间跨度与剧情不匹配

---

## 地点一致性

### 场景描述

**检查项目**：
- [ ] 主要场景描述是否前后一致
- [ ] 地点名称是否前后一致
- [ ] 地理位置关系是否合理
- [ ] 场景细节是否前后一致

**常见错误**：
- 同一个地方描述前后不同
- 地理位置关系混乱
- 场景细节矛盾

### 移动逻辑

**检查项目**：
- [ ] 角色移动是否符合地理逻辑
- [ ] 移动时间是否合理
- [ ] 是否出现瞬移情况
- [ ] 交通工具使用是否合理

**常见错误**：
- 刚在北京，下一章突然出现在上海，没有交代
- 移动时间不合理
- 交通工具使用混乱

## 剧情逻辑一致性

### 因果关系

**检查项目**：
- [ ] 事件因果关系是否合理
- [ ] 是否有逻辑漏洞
- [ ] 角色动机是否合理
- [ ] 结果是否符合逻辑

**常见错误**：
- 因果关系不成立
- 逻辑漏洞（如主角明明可以简单解决问题，却绕大圈）
- 角色动机不合理

### 冲突解决

**检查项目**：
- [ ] 冲突解决方式是否合理
- [ ] 是否有更简单的解决方式
- [ ] 解决过程是否符合角色能力
- [ ] 解决结果是否符合设定

**常见错误**：
- 解决方式太简单/太复杂
- 不符合角色能力范围
- 结果与设定矛盾

### 反派行为

**检查项目**：
- [ ] 反派行为是否符合其智商设定
- [ ] 反派动机是否合理
- [ ] 反派决策是否符合其利益
- [ ] 反派失败原因是否合理

**常见错误**：
- 反派智商突然下线
- 反派行为不符合其利益
- 反派失败太突兀

## 伏笔管理

### 伏笔记录

**需要记录的伏笔**：
- 埋下的伏笔内容
- 埋下的章节位置
- 计划回收的章节
- 实际回收情况

### 伏笔检查

**检查项目**：
- [ ] 所有伏笔是否都有记录
- [ ] 伏笔是否都得到回收
- [ ] 回收方式是否合理
- [ ] 是否有遗漏的伏笔

**常见错误**：
- 伏笔埋了但忘了回收
- 回收方式不合理
- 伏笔前后矛盾

### 伏笔回收时机

**好的回收时机**：
- 关键转折点
- 高潮部分
- 揭秘时刻
- 打脸时刻

**不好的回收时机**：
- 无关紧要的场景
- 已经过去很久的伏笔
- 读者已经忘记的伏笔

## 数值一致性

### 财富数值

**检查项目**：
- [ ] 财富增长是否合理
- [ ] 收入/支出是否匹配
- [ ] 资产估值是否合理
- [ ] 消费水平是否与财富匹配

**常见错误**：
- 前面说月薪5000，后面突然有百万存款
- 公司估值前后矛盾
- 消费水平与收入不匹配

### 实力数值

**检查项目**：
- [ ] 战斗力数值是否前后一致
- [ ] 能力等级是否正确提升
- [ ] 对手实力是否合理
- [ ] 胜负结果是否符合实力对比

**常见错误**：
- 主角实力忽高忽低
- 对手实力设定不合理
- 胜负结果与实力对比不符

### 公司数据

**检查项目**：
- [ ] 公司规模是否前后一致
- [ ] 员工数量是否合理
- [ ] 营收/利润是否合理
- [ ] 市场份额是否合理

**常见错误**：
- 公司规模前后矛盾
- 员工数量变化不合理
- 财务数据前后不一致

## 快速检查流程

### 写新章节前

1. 回顾上一章结尾
2. 检查角色当前状态
3. 确认时间线位置
4. 查看待回收伏笔

### 写新章节后

1. 检查角色信息一致性
2. 检查时间线合理性
3. 检查地点描述一致性
4. 检查剧情逻辑
5. 更新伏笔记录

### 定期检查

每10章进行一次全面检查：
1. 角色信息全面核对
2. 时间线梳理
3. 伏笔状态更新
4. 数值核对
