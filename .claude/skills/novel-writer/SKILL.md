# 都市逆袭爽文写作 Skill

帮助用户创作都市逆袭类网络爽文，支持大纲生成、章节创作和剧情一致性检查。

## 工作流程

### 阶段 1: 需求收集

当用户触发此 Skill 时，使用 `AskUserQuestion` 收集以下信息：

**核心概念**（必问）：
```
问题: "你的故事核心概念是什么？"
选项:
- "重生逆袭：回到过去，利用未来记忆逆袭人生"
- "系统流：获得神秘系统，完成任务变强"
- "隐藏身份：主角有隐藏的强大背景"
- "我来描述其他概念"
```

**主角设定**（必问）：
```
问题: "主角是什么身份？"
选项:
- "普通人逆袭：从底层一步步往上爬"
- "落魄少爷：曾经辉煌，现在落魄，重新崛起"
- "退伍/回归：强者回归都市"
- "我来描述其他身份"
```

**核心冲突**（必问）：
```
问题: "故事的主要冲突是什么？"
选项:
- "商战：商业竞争、公司斗争"
- "家族：家族恩怨、继承权争夺"
- "复仇：向曾经欺辱自己的人复仇"
- "我来描述其他冲突"
```

收集完成后，进入大纲生成阶段。

### 阶段 2: 大纲生成

基于收集的信息，生成完整故事大纲。参考 `references/urban-reverse-tropes.md` 中的类型套路。

**大纲结构**（参考 `references/outline-template.md`）：

1. **故事概述**：一句话概括、类型标签、目标读者
2. **世界观设定**：时代背景、社会环境、特殊设定（如有）
3. **角色设定**
   - 主角：姓名、年龄、背景、性格、初始能力、成长路线
   - 女主：姓名、与主角关系、性格特点
   - 反派：姓名、身份、与主角的冲突、结局
   - 配角：关键配角设定
4. **主线剧情**：起因 → 发展 → 高潮 → 结局
5. **章节规划**：每卷/每阶段的核心事件和转折点

**生成规则**：
- 大纲控制在 800-1200 字
- 每个角色要有鲜明特点和记忆点
- 主线清晰，副线不喧宾夺主
- 预留足够的爽点和反转空间

生成大纲后，展示给用户确认。

### 阶段 3: 章节生成

用户确认大纲后，根据需求生成单章内容。

**章节结构**：
1. **开篇**：承接上章或新场景引入（200-300字）
2. **发展**：推进剧情、展开冲突（800-1200字）
3. **高潮**：本章核心爽点或转折（300-500字）
4. **钩子**：悬念结尾，吸引读者继续（100-200字）

**写作要求**：
- 每章 1500-2500 字
- 节奏紧凑，不拖泥带水
- 对话自然，符合角色性格
- 每章至少一个小爽点或反转
- 结尾必须有悬念钩子

**悬念钩子类型**（参考）：
- 危机型："门被推开，来者正是..."
- 反转型："然而他不知道的是..."
- 揭秘型："当他看到那份文件时，瞳孔骤然收缩..."
- 升级型："就在这时，他感受到了一股前所未有的力量..."

### 阶段 4: 一致性检查

当用户提供新章节内容或要求检查时，进行一致性检查。

检查项目（参考 `references/consistency-checklist.md`）：
1. **角色一致性**：名字、外貌、性格、能力是否前后一致
2. **时间线**：事件顺序是否合理，时间跨度是否正确
3. **地点**：场景描述是否前后一致
4. **剧情逻辑**：因果关系是否合理，是否有矛盾
5. **伏笔回收**：之前埋的伏笔是否得到回应

检查完成后，生成检查报告，指出问题并提供修改建议。


## 写作风格指南

### 语言风格
- 简洁有力，不堆砌辞藻
- 对话口语化，符合都市背景
- 描写点到为止，给读者想象空间
- 适当使用短句增强节奏感

### 爽点设计
- 打脸要干脆利落
- 逆袭要有铺垫和对比
- 实力提升要有仪式感
- 反转要出人意料又在情理之中

### 禁忌事项
- 避免主角无脑开挂
- 避免反派智商下线
- 避免剧情注水拖沓
- 避免前后矛盾

## 工具使用

### 一致性检查
```bash
python scripts/consistency_checker.py <故事目录>
```
扫描故事目录中的所有章节，检查角色、时间线、地点等一致性问题，生成检查报告。

### 章节生成
```bash
python scripts/chapter_generator.py <大纲文件> --chapters 100 --start 1
```
根据故事大纲生成详细的章节规划，输出到 `chapters_outline.md`。
