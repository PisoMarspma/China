# 添加新游戏 Skill

当用户想要添加新游戏时，使用此 skill 进行问答引导。

## 工作流程

### 第一步：收集游戏基本信息

向用户提问以下问题（使用 AskUserQuestion 工具）：

1. **游戏名称**：这个游戏叫什么？（中文名称，显示在菜单上）
2. **游戏类型**：是什么类型的游戏？
   - 射击类（如坦克大战、打飞机）
   - 益智类（如俄罗斯方块）
   - 体育类（如台球）
   - 动作类（如下100楼、赛车）
   - 其他类型

3. **操作方式**：玩家如何操作？
   - 键盘方向键
   - 鼠标点击/移动
   - 键盘+鼠标组合
   - 其他方式

4. **游戏目标**：游戏的胜利/失败条件是什么？
   - 得分制（达到目标分数）
   - 生存制（存活时间）
   - 通关制（完成特定任务）
   - 对战制（击败对手）

### 第二步：确认设计细节

根据用户回答，进一步询问：

1. **游戏难度**：难度如何递增？
   - 速度加快
   - 敌人增多
   - 时间限制
   - 其他方式

2. **视觉风格**：
   - 保持现有风格（霓虹灯光效、深色背景）
   - 有特殊需求

3. **音效需求**：
   - 射击/碰撞音效
   - 得分音效
   - 游戏结束音效

### 第三步：生成代码框架

基于收集的信息，生成：

1. **游戏类结构**（继承 GameBase）
   ```
   class NewGame extends GameBase {
     constructor(core) { ... }
     get title() { return "游戏名称"; }
     get hint() { return "操作说明"; }
     onEnter() { ... }
     update(dt) { ... }
     draw(ctx) { ... }
   }
   ```

2. **必要组件**：
   - 玩家对象
   - 游戏元素（敌人/道具/障碍物等）
   - 碰撞检测
   - 计分系统
   - 游戏结束逻辑

3. **特效集成**：
   - 使用 `core.fx.burst()` 粒子效果
   - 使用 `core.fx.addShake()` 屏幕震动
   - 使用 `core.audio.blip()` 音效

### 第四步：集成到项目

1. 在 `game.js` 末尾添加新游戏类
2. 在 `Core` 类的 `games` 对象中注册
3. 在 `index.html` 添加菜单按钮
4. 更新菜单显示文本
5. 添加快捷键绑定（数字键 7、8、9...）

### 第五步：测试与优化

1. 确保游戏能正常启动和退出
2. 检查碰撞检测是否准确
3. 验证计分系统
4. 测试游戏结束条件
5. 调整难度平衡性

## 代码规范

- 使用现有的工具函数：`clamp`, `lerp`, `rand`, `randi`, `roundRect`
- 保持一致的代码风格
- 遵循现有游戏的结构模式
- 使用 `TAU` 常量（Math.PI * 2）
- 所有文本使用中文

## 示例问题模板

```
我想添加一个新游戏，请告诉我：

1. 游戏名称是什么？
2. 是什么类型的游戏？（射击/益智/体育/动作/其他）
3. 玩家如何操作？（键盘/鼠标/组合）
4. 游戏的胜利条件是什么？
5. 难度如何随时间变化？
```

## 注意事项

- 确保新游戏与现有游戏风格统一
- 保持代码简洁，避免过度复杂
- 优先使用现有代码中的模式和函数
- 游戏应该容易理解，操作直观
