# 优化游戏 Skill

当用户想要优化现有游戏时，使用此 skill 进行分析和改进。

## 工作流程

### 第一步：识别目标游戏

询问用户要优化哪个游戏：
1. 坦克大战
2. 俄罗斯方块
3. 打飞机
4. 台球（九球简化）
5. 下100楼
6. 赛车

或者询问是否要优化整个项目。

### 第二步：分析优化维度

从以下维度分析游戏，询问用户关注哪些方面：

#### 1. 性能优化
- **帧率稳定性**：检查是否有卡顿
- **内存使用**：检查是否有内存泄漏
- **计算效率**：优化循环和碰撞检测
- **渲染优化**：减少不必要的绘制操作

#### 2. 代码质量
- **代码结构**：是否符合现有模式
- **可读性**：命名、注释、格式
- **可维护性**：模块化、职责分离
- **重复代码**：提取公共函数

#### 3. 游戏体验
- **操作手感**：响应速度、流畅度
- **难度平衡**：是否太难或太简单
- **视觉反馈**：特效、动画是否足够
- **音效配合**：音效时机和类型

#### 4. 功能增强
- **新功能**：添加缺失的功能
- **改进现有功能**：优化现有机制
- **UI/UX 改进**：界面和交互优化

### 第三步：具体优化方案

#### 性能优化检查清单

```
1. 对象池管理
   - 子弹、粒子等频繁创建的对象
   - 使用对象池避免 GC 压力

2. 碰撞检测优化
   - 空间分区（如网格划分）
   - 减少不必要的检测

3. 渲染优化
   - 脏矩形渲染
   - 减少状态切换
   - 批量绘制相同类型元素

4. 计算优化
   - 缓存计算结果
   - 避免重复计算
   - 使用位运算
```

#### 代码质量改进

```
1. 提取公共方法
   - 移动逻辑
   - 碰撞响应
   - 边界检查

2. 统一命名规范
   - 变量名清晰
   - 函数名表达意图

3. 添加注释
   - 复杂算法说明
   - 关键逻辑解释

4. 错误处理
   - 边界条件
   - 异常情况
```

#### 游戏体验优化

```
1. 操作优化
   - 输入缓冲
   - 预输入
   - 自动瞄准辅助

2. 视觉反馈
   - 命中特效
   - 得分动画
   - 状态指示器

3. 音效优化
   - 音效时机
   - 音效层次
   - 背景音乐

4. 难度曲线
   - 渐进式难度
   - 动态调整
   - 挑战与奖励平衡
```

### 第四步：实施优化

根据分析结果，按优先级实施：

1. **高优先级**：影响游戏体验的问题
2. **中优先级**：性能和代码质量改进
3. **低优先级**：功能增强和美化

### 第五步：测试验证

1. **功能测试**：确保优化后功能正常
2. **性能测试**：验证性能提升
3. **体验测试**：确认用户体验改善
4. **回归测试**：检查是否引入新问题

## 各游戏优化建议

### 坦克大战
- 优化子弹碰撞检测
- 改进敌人 AI 行为
- 添加更多地图元素
- 优化粒子效果性能

### 俄罗斯方块
- 优化方块旋转逻辑
- 改进预览系统
- 添加保持功能
- 优化消行动画

### 打飞机
- 优化敌人生成算法
- 改进子弹模式
- 添加道具系统
- 优化大量子弹时的性能

### 台球
- 优化物理模拟精度
- 改进瞄准辅助
- 添加球杆力度控制
- 优化球体碰撞计算

### 下100楼
- 优化平台生成算法
- 改进碰撞检测
- 添加特殊平台类型
- 优化滚动性能

### 赛车
- 优化车辆生成逻辑
- 改进碰撞检测
- 添加道具系统
- 优化道路渲染

## 工具使用

使用以下工具进行分析：

1. **Read**：查看游戏代码
2. **Grep**：搜索特定模式
3. **Edit**：修改代码
4. **Bash**：运行测试

## 输出格式

优化完成后，提供：

1. **优化总结**：做了哪些改进
2. **性能对比**：优化前后的差异
3. **测试结果**：功能是否正常
4. **后续建议**：还可以进一步优化的地方

## 注意事项

- 保持向后兼容
- 不改变游戏核心玩法
- 优先解决明显问题
- 小步迭代，逐步优化
